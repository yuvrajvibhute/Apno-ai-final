## 🌟 Key Features

1. **Brand Identity & Luxury Palette**:
   - Styled with `--brand: #C9A24D` (Regal Gold) and `--brand-dark: #2B2B2B` (Charcoal).
   - Editorial typography combining **Cormorant Garamond** (serif) and **Plus Jakarta Sans** (sans-serif).

2. **Hero Section**:
   - Emotional headline, high-impact background visuals, trust metrics (150+ weddings, 100% on-time delivery), and smooth-scrolling call-to-action buttons.

3. **About Section**:
   - 40+ word warm narrative detailing the studio's emotion-first approach and 3 key value pillars.

4. **Curated Services (3 Cards)**:
   - **Candid Wedding Photography**: Zero stiff poses, capturing raw tears and laughter with handcrafted leather albums.
   - **Pre-Wedding Shoots**: Scenic outdoor stories across Pune and fort landscapes with save-the-date reels.
   - **Cinematic Wedding Films**: 4K multi-cam coverage, drone perspectives, 60s trailers, and full-length feature films.

5. **Client Testimonials**:
   - Realistic couple reviews from Baner and Kothrud, Pune.

6. **Interactive Portfolio Gallery & Lightbox (Bonus JavaScript Feature)**:
   - 6 high-resolution Indian wedding photography moments in a responsive grid.
   - Vanilla JavaScript modal lightbox with image preview, captions, click-outside close, and `Escape` key support.

7. **Interactive Booking Inquiry Form**:
   - Complete with client name, phone, wedding date, service selection, and instant confirmation feedback.

8. **Floating WhatsApp "Book Now" Button**:
   - Quick-contact floating action button linking directly to WhatsApp with a pre-filled booking inquiry.

9. **Mobile-First & Fully Responsive**:
   - Responsive hamburger navigation menu.
   - Meets 2026 mobile web accessibility and touch-target standards (min 48px).

## 🛠️ Tech Stack

- **HTML5**: Clean, semantic markup.
- **CSS3**: Modern CSS Variables, Flexbox, Grid, smooth animations, and responsive media queries.
- **Vanilla JavaScript**: Lightweight DOM manipulation for the lightbox modal, mobile navigation, and contact form handling (zero external libraries/frameworks).
